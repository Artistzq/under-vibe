# 文件系统与路径

AI 对你说：*"把文件放到项目的 src 目录下，路径是 ./src/App.js"*

你：*"点 是斜杠？点斜杠又是什么意思？"*

如果你经常被这些路径问题搞懵，这一章就是为你准备的。

## 🎯 实战：理解路径

### 绝对路径 vs 相对路径

这是路径问题的核心。搞懂了这个，90% 的路径错误就不会难住你了。

#### 绝对路径

**从"根目录"开始，完整描述一个文件的位置。**

就像写收货地址："中国北京市朝阳区XX街道XX号"——无论你在哪，这个地址都能找到。

```bash
# macOS / Linux 的绝对路径
/Users/yourname/Documents/my-project/src/App.js

# Windows 的绝对路径
C:\Users\yourname\Documents\my-project\src\App.js
```

特点：
- ✅ 永远不会出错
- ❌ 写起来很长
- ❌ 换一台电脑就不适用了（别人的用户名可能不是 yourname）

#### 相对路径

**相对于"你现在所在的位置"，描述文件的位置。**

就像你在房间里说："书架上第二层左边那本书"——只有在这个房间里才有效。

```bash
# 如果你在 my-project 文件夹里
./src/App.js
```

特点：
- ✅ 写起来短
- ✅ 换电脑也能用（只要项目结构一样）
- ❌ 你所在的位置变了，路径就变了

### 相对路径的三个符号

这三个符号是理解相对路径的关键，一定要记住：

| 符号 | 意思 |
|-----|------|
| `.` | 当前目录（我现在站的地方） |
| `..` | 上一级目录（往回走一步） |
| `/` | 如果在开头，表示根目录；如果在中间，表示分隔 |

::: tip 💡 举个例子
假设你现在在 `my-project/src` 文件夹里：

- `./App.js` → 当前目录下的 App.js（就是同一个文件夹里）
- `../package.json` → 回到上一级（到 my-project），然后找 package.json
- `../../Documents` → 回到上两级，然后找 Documents 文件夹
:::

## 🧩 底层揭秘：文件系统是什么？

### 一切都是树

你的电脑里的所有文件，组织起来就是一棵倒置的树：

```
/ （根目录）
├── Users/
│   └── yourname/
│       ├── Documents/
│       │   ├── my-project/
│       │   │   ├── src/
│       │   │   │   └── App.js
│       │   │   └── package.json
│       │   └── photo.jpg
│       └── Desktop/
└── System/
```

- 最顶层叫"根目录"（Root）
- 每一个文件夹都是一个"节点"
- 每一个文件都是一个"叶子"

当你在终端里输入 `cd` 命令时，你就是在这棵树上爬上爬下。

### 为什么用斜杠？

树是立体的，但文字是一维的。
我们用斜杠 `/`（Windows 是反斜杠 `\`）来表示"进入下一层"。

```
/Users/yourname/Documents/my-project/src/App.js
 ↑      ↑        ↑         ↑          ↑    ↑
 根   Users   yourname  Documents   src  App.js
```

就像一串地址，一层一层地指下去。

## ⚠️ 常见坑

### 坑 1：我在哪？

最常见的错误：你以为你在 A 文件夹，其实你在 B 文件夹。

**记住：输入任何路径命令之前，先 `pwd` 确认一下你在哪。**

这能帮你避免 80% 的路径问题。

### 坑 2：斜杠方向搞反

- macOS / Linux：正斜杠 `/`
- Windows：反斜杠 `\`（但 PowerShell 也支持正斜杠）

现在大部分工具都兼容两种斜杠了，不用太纠结。

### 坑 3：文件名有空格

如果文件名或文件夹名有空格，要用引号括起来：

```bash
cd "My Documents"
```

不然终端会以为空格是命令的分隔符，把一个路径拆成多个部分。

## 📝 术语表

| 术语 | 意思 |
|-----|------|
| **文件系统** | 电脑存放和组织文件的方式 |
| **绝对路径** | 从根目录开始的完整路径，在哪都能用 |
| **相对路径** | 相对于当前位置的路径，更短但位置变了就失效 |
| **根目录** | 文件系统最顶层，用 `/` 表示 |
| `.` | 当前目录 |
| `..` | 上一级目录 |
| **路径分隔符** | `/` 或 `\`，用来分隔路径中的每一层 |
