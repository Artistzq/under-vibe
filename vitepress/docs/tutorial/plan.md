# 学习路径与目录规划（预目录）

> 本文档是 Under Vibe 教程内容的**预目录**：它提前描述整条学习路径、目标目录结构，以及每一篇文章的位置、状态与写作意图。真正的站点目录由 `vitepress/docs/.vitepress/config.mts` 根据**实际存在的文档**动态生成——只写进规划、尚未成文的文章，不会出现在导航里。

::: tip 💡 给内容创作者
动笔新文章前，先读本文档。文章路径、标题、一句话定位以这里为准；完成后更新对应条目的状态，并把链接登记进 `config.mts` 侧边栏。
:::

## 一、学习路径总览

内容按"真实使用场景"组织成**一站一站**的旅程，读者按顺序走完即可覆盖 vibecoding 所需的全部基本功：

| 阶段 | 章节 | 回答的问题 | 前置要求 |
|------|------|-----------|---------|
| 前言 | `why-this-project` | 我为什么要学这些 | 无 |
| 第一站 · 上手 | `01-getting-started` | 怎么开始一个新项目 | 前言 |
| 第二站 · 基础 | `02-cs-fundamentals` | 电脑到底是怎么工作的 | 上手篇 |
| 第三站 · 工程 | `03-engineering` | 从写代码到做项目还差什么 | 上手篇 |
| 第四站 · 排错 | `04-debugging` | 报错了怎么办 | 上手篇 |
| 第五站 · AI | `05-ai` | 怎么跟 AI 副驾驶高效协作 | 前三站任意 |

路线不追求"学完所有理论再动手"，而是**边做边补**：第一站就能开始干活，后面每一站都是在踩坑后按需回来补的底层知识。

## 五、维护约定

1. **目录是动态的**：`config.mts` 侧边栏只登记已实际完成的文章；规划中但未编写的文章只存在于本文档，不创建占位文件。
2. **新文章写作流程**：按本文档的路径与标题写作 → 完成后把本文档对应条目的状态改为 ✅ → 在 `config.mts` 侧边栏登记链接。
3. **新增主题**：先在本"预目录"中规划（编号、定位、所在篇），再落笔成文，避免标题先于内容出现。
4. **编号原则**：`NN-` 前缀表示该篇在同一篇目内的学习顺序，移动文章时保持编号与侧边栏一致。
